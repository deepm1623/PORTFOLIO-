A premium personal portfolio website built to present professional experience, project outcomes, and credentials in a visually polished, recruiter-friendly format.

This project focuses on modern UI/UX, smooth interaction design, and responsive performance across devices while maintaining clean, maintainable frontend architecture.

---

## 🔗 Live Demo

- **Portfolio Demo:** [https://deepmakwana-portfolio.vercel.app](https://deepmakwana-portfolio.vercel.app)

---

## ✨ Features

- Modern hero section with strong personal branding and CTA flow.
- Fully responsive layout optimized for desktop, tablet, and mobile.
- Dark/Light theme toggle with **localStorage** persistence.
- Smooth scroll-based reveal animations using `IntersectionObserver`.
- Animated stat counters for dynamic first impression.
- Project showcase with category-based filtering.
- Rich project cards with live project external links.
- Resume timeline with experience and education highlights.
- Certifications section with PDF preview/download links.
- Skills section with concise capability tagging.
- Contact section with direct call CTA and polished social links.
- Glassmorphism-inspired premium visual system and micro-interactions.
- SEO-friendly semantic HTML structure and accessibility-conscious markup.

> **Note:** Authentication and external API integrations are not currently implemented in this version.

## 🧰 Tech Stack

| Layer | Technologies |
|---|---|
| Frontend | HTML5, CSS3, Vanilla JavaScript (ES6+) |
| UI/UX | Custom Design System, Glassmorphism, Gradient Effects, Micro-animations |
| Icons & Assets | Ionicons, Google Fonts (`Space Grotesk`) |
| State/Persistence | Browser `localStorage` (theme mode persistence) |
| Deployment (Recommended) | Vercel / Netlify / GitHub Pages |
| Backend | Not required (static frontend portfolio) |
| Database | Not required |

## ⚙️ Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/your-username/portfolio.git
   ```

2. **Navigate to project folder**
   ```bash
   cd portfolio
   ```

3. **Run locally (choose one option)**

   - Option A: Open `index.html` directly in browser  
   - Option B: Serve with a local server (recommended)
     ```bash
     # Python 3
     python -m http.server 5500
     ```

4. **Open in browser**
   ```txt
   http://localhost:5500
   ```

## 📁 Folder Structure

```txt
Portfolio/
├── index.html              # Main website structure
├── styles.css              # Full styling, layout, animations, themes
├── script.js               # Theme, filtering, animations, interactions
├── icon-quote.svg          # UI decorative/icon asset
├── images/                 # Profile image + certificate preview images
├── pdf/                    # Resume and certification PDF files
├── Projects/               # Project showcase screenshots/previews
└── .vscode/                # Workspace/editor settings
```

## ▶️ Usage

- Edit personal content in `index.html` (bio, projects, skills, links).
- Update visual system and responsive behavior in `styles.css`.
- Extend interactivity in `script.js` (filters, counters, theme behavior).
- Replace portfolio assets inside `images/`, `Projects/`, and `pdf/`.
- Deploy to your preferred static hosting platform for production use.
